# Image Bundling Study

An empirical study of bundling many small web images (icons, product thumbnails,
decorations) into a single atlas image versus serving them individually: byte savings at
matched visual quality, load timing, and decode cost, across codecs (PNG, JPEG, WebP,
AVIF, JPEG XL) and protocols (HTTP/1.1, HTTP/2, HTTP/3).
