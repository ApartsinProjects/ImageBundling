## Bugs found and fixed
- REJECTION-GRADE: paper prose claimed chunking gives loss-recovery (atlas 0.9x, chunks 1.8x) from phase2v3 n=5 noise; phase2v4 uniform re-run (now the cited Table 2) shows atlas1 1.50x vs atlas4 1.54x, NO advantage. The prose contradicted its own table. Rewrote to make no loss-recovery claim; chunking benefit is cache granularity only.
- Network headline speedup was inflated in phase2v3 (uneven reps, slow individual baseline): localhost-h1 flat-art 8.3x. Uniform phase2v4 re-run (randomized order) corrected it to 4.5x; paper headlines updated. Monotonicity inversion (localhost>fast individual) also vanished with the clean run.
- T3 matched-SSIM saving was non-monotone (bounced +/- with size); root-caused via ladder dump to sub-0.01 SSIM crossings between near-identical atlas/individual quality curves amplified by log-byte interpolation. Fix: equal-quality byte comparison for homogeneous content where the two quality curves coincide.
- atlas_optimizer pack_atlas encoded lossy WebP for lossless groups (mismatch); strip routing for lossless was also unverified (E3.7 proved strip only for PNG). Reverted lossless groups to byte-bundle (proven zero-penalty); strip-PNG left as documented finding + backlog.
- Phase 2 harness: pages fetched each image twice (markup + JS preload) because Cache-Control: no-store blocked request coalescing; fresh-browser-per-load already guarantees cold cache, so no-store removed. Resource-timing buffer raised to 4096 (default 250 truncated byte accounting). Verified: atlas transfers exactly file size, unimodal timings.
- gpu2modal modal_runner autowrap --run built an incomplete argparse.Namespace (missing allow_duplicate/watchdog/fanout fields); patched in the skill and pushed.
- Photo asset set: Picsum seeded URLs return a finite pool; 108/500 tiles pixel-identical. Affects similarity-ordering interpretation; dedup flag added to e31_ordering.
- fetch_assets.sh: Python on Windows emits CRLF; `$(python_gen)` kept trailing `\r` in
  codepoints, corrupting every emoji URL except the last line. Fix: `| tr -d '\r'`.
