# Fable brainstorm: PNG/WebP winning use cases and test designs (2026-08-28)

Generated by a Fable agent. Prioritized use cases where PNG and WebP atlasing WIN,
with runnable test designs. Effect guesses are hypotheses, not measurements.

## Top-3 tests to run next (agent's ranking by win x realism x cheapness)
1. **T2 VP8L near-lossless + dedup** (+20-40% hyp): flat-art icon corpus, WebP-lossless
   atlas vs individual + PNG; dup-heavy variant with dup-adjacent vs random ordering.
   Tests two open hypotheses at once (near-lossless win + LZ dedup). Shares corpus w/ T1.
2. **T1 shared-palette PNG icons** (+25-45% hyp): 200 icons, pooled <=256-color PLTE +
   vertical strip vs individual RGBA/paletted PNG and grid. The flagship PNG claim
   (every design system ships an icon set). Invariant: pooled-palette result must be
   byte-identical after decode (exactness check) or the "lossless" claim is void.
3. **T3 e-commerce thumbnails** (+10-18% hyp): product photos on white, sizes 48-112px,
   WebP lossy atlas vs individual at matched SSIM. Anchors the WebP-lossy claim in the
   biggest commercial surface; break-even may be nearer 110-120px on white backgrounds.

## PNG winning use cases (lever in parens)
- Design-system icon libraries (Material Symbols, Font Awesome, Polaris) - homogeneity
  + small + flat + alpha; shared-palette strip +25-45%. Highest commercial relevance.
- Flag/currency/language selector sets - flat, palette overlap; +20-35%.
- Sprite-animation frames / Lottie fallback - near-duplicate frames in LZ window; +15-30%.
- E-commerce variant swatches/badges - exact dups + tiny; explicit dedup +15-25%.
- Map pins/markers (Mapbox sprite convention) - shared silhouette; +20-30%.
- Chat/reaction emoji packs - flat+alpha but gradient-heavy emoji weaken palette; +10-20%.
- Doc UI chrome (kbd keys, toolbar crops), QR/barcode batches - niche, +15-25%.

## WebP winning use cases
- E-commerce thumbnail walls at mobile density (50-100px) - +15% at 56px to break-even
  ~100px; biggest commercial surface.
- Avatar walls (comment threads, "liked by") - small + heavy exact dups + huge
  request-collapse; +15-25% with explicit dedup.
- Flat-art icons in VP8L near-lossless - inherits dedup win, may beat PNG-strip AND
  WebP-lossy; +20-40%.
- Sticker/GIF-replacement trays - flat+alpha, burst-fetched; +5-12%, latency headline.
- Map raster sprite sheets in VP8L - Mapbox ships PNG today; WebP-ll typically -20-30%.

## Where PNG/WebP atlas should surprisingly beat even JPEG
1. Tiny thumbnails 32-48px: WebP-lossy atlas beats the JPEG ATLAS by 25-35% (JPEG 8x8
   DCT + chroma structure punishing at small sizes). Correct headline for avatar/thumb
   walls is "beats best JPEG option," not just "beats individual WebP".
2. Flat art at matched SSIM 0.97: JPEG rings on hard edges, so lossless VP8L/PNG can be
   SMALLER than the JPEG atlas while being pixel-perfect (counterintuitive lossless <
   lossy row). Free to add as a JPEG-atlas column in T1/T2.
3. Alpha assets: JPEG structurally disqualified; PNG-vs-WebP is the only honest set.
4. Screenshot/chart thumbnails: text-on-flat makes JPEG bleed even at 200px+, the one
   large-tile case where JPEG doesn't win back.

## Harness discipline (from the agent, matches project rules)
Co-compute all conditions in ONE pass on ONE corpus/seed; match PER-TILE SSIM in both
arms (whole-image SSIM lets bad tiles hide); one pre-stated invariant per test
(T5: shuffled must never beat temporal; T1: paletted atlas byte-identical after decode).
